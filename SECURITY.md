# Security Policy

**PLEASE DON'T DISCLOSE SECURITY-RELATED ISSUES PUBLICLY.**

## Reporting a Vulnerability

If you discover a security vulnerability within Wave, please report it privately through GitHub: open the [Security tab](https://github.com/thedevdojo/wave/security) and click **Report a vulnerability**, or go straight to the [new advisory form](https://github.com/thedevdojo/wave/security/advisories/new).

Please include the affected version, the steps to reproduce and the impact. We'll follow up on the advisory.
